Planetaria OS: one door, four desks

Planetaria OS is the private workspace where the Planetaria team works by talking to one orchestrator, Planetaria Comander, from Claude Code. M3 reorganised it around desks: each desk owns one function, has a lead role, a program with human gates, and an independent reviewer. Everything is in Git, checked by script, and grows or shrinks on purpose.

How it was tested. Ten requests and their right answers were fixed before routing was built; a fresh agent reading only the repo got all ten. Another agent added a throwaway desk in one session, guided only by the checker. Every tightened check was proven with a case that had to fail, and did.

How we will work

  1. Open the repo in Claude CodeTerminal or VS Code. One session per folder, so parallel work never overwrites.
  2. Talk to ComanderAsk for the pulse and the next step, or use a desk shortcut like /product-desk.
  3. Desks produce, reviewers checkFacts, proposals and unknowns stay labelled. Identity changes only with a human decision on record.
  4. Close with /upcIt logs friction, runs the checker, refuses secrets and private files, then pushes.
